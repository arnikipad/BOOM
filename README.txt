## Overview
This repository contains a proof-of-concept (PoC) for modifying the system boot sequence and BIOS splash screen on Windows-based environments.

## 🛑 CAUTION
**NEVER run this on a physical machine.** This script is designed to overwrite system partitions and modify firmware settings. Use a Virtual Machine.

## Technical Analysis
The code demonstrates:
1. MBR/GDI
2. Old Peekaboo sound.
3. Nice Colors and Design.
